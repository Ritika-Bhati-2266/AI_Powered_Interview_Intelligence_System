# AI Interview Intelligence System Frontend

This is a modern, beautiful Next.js 14 Web Application built using TypeScript and Tailwind CSS.

## Features
- **Candidate Dashboard**: Sleek and premium glassmorphic dark mode dashboard.
- **Resume Upload & Parsing Portal**: Drag-and-drop resume uploader showcasing parsed result metrics.
- **Live Interview Simulator**: Embeds active video/audio canvas and real-time WebSocket PCM speech transcription with words highlights and alerts.

## Structure
- `/src/app`: Page router and layouts.
- `/src/components`: Premium custom dashboard and video components.
- `/src/hooks`: Live media recording and websocket listeners.

## Launching Local Dev
Ensure node/npm is installed.
```bash
npm install
npm run dev
```
Open `http://localhost:3000` to start.
